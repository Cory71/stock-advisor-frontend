# Capstone Project Planning

## 1. Assignment Overview

- [ ] **Due:** No due date
- [ ] **Points:** 0
- [ ] **Submission options:** text entry box, website URL, media recording, or file upload
- [ ] The last 4 weeks of the course will be spent of the capstone project, where you will apply all the concepts you learned during the bootcamp in a big project where you will have to problem-solve and create a new piece of software that implements good coding practices.

## 2. Goal

- [ ] This assignment will allow you to demonstrate your ability to design, develop, and deploy software applications using industry-standard practices and JavaScript frameworks.
- [ ] Create and deploy a fully functional software application that showcases your skills in software design and development.

## 3. Proposal Requirements

- [ ] Choose an idea for your application.
- [ ] It could be a web or mobile app that solves a problem, entertains, educates, or serves any other purpose you find meaningful.
- [ ] Write a brief project proposal (1-2 pages) outlining your idea, its features, target audience, and technology stack you plan to use.
- [ ] Submit this proposal for approval before starting the development.
- [ ] After you submit your proposal and get an approval by your instructor, you can continue with the Capstone Project.
